Privacy Policy — Personal Services

Last updated: November 7, 2026

This application ("Personal Services") is a personal, self-hosted assistant operated by Amine Adjimi. This policy explains how Google user data accessed through the Google APIs is handled.

Data accessed

With the owner's explicit authorization, the application may access the owner's own Google account data: profile information (email address, name), Gmail messages, Google Calendar events, Google Drive files, Google Docs and Sheets documents, and contacts.

How data is used

All data is accessed and processed locally, on the owner's own computer, solely for the owner's personal use (reading mail, managing calendars and files, drafting documents). No data is sold, rented, transferred to, or shared with any third party. No advertising identifiers are used. No human review of data takes place outside the owner's machine.

Data storage

OAuth tokens are stored locally in the owner's home directory, protected by the operating system's file permissions. No Google user data is copied to external servers or cloud storage by this application.

Data deletion and revocation

Access can be revoked at any time from the Google Account permissions page (myaccount.google.com/permissions), which immediately invalidates the tokens. The owner can delete locally stored tokens by removing the application's token files.
